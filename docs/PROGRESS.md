## 2026-09-19

### 问答模式改造为模型自主检索（agentic QA）

| 项 | 内容 |
| --- | --- |
| 变化 | qa 模式不再固定「一次检索 → 生成」，改为模型通过 `search_book` 工具（原生 OpenAI tools 参数、tool_choice auto）多轮自主检索；`Tutor.agent_stream` 新增工具循环、跨轮稳定 C 编号证据池与流式预览 |
| 预算 | `AGENT_MAX_CALLS` 工具调用上限与 `AGENT_MAX_ROUNDS` 循环轮数上限（当前 10 / 12）；超限调用不执行，向模型返回 JSON 错误消息 |
| 安全网 | ①模型不调工具且证据池为空时自动以原问题检索一次；②请求异常且本轮无内容时同供应商盲重试一次；③切换备用供应商时重建与供应商无关的上下文（system + 原问题 + 证据池）并重置轮数；④整体失败且未流出任何可见增量时应用层透明回退经典固定检索管线 |
| 不变 | explain / outline / quiz 仍走固定检索管线；每次工具检索仍限定当前书与章节范围 |
| 验证 | 线上冒烟：简单问题 1 次检索约 8 秒；复杂问题 6 次检索、25 段证据、10 个引用，期间真实发生上游 422 → 重试失败 → 备用 GLM 干净交接完成回答；浏览器实测检索状态行实时出现、终答行内 [C1][C2][C3] 按钮 |

### 工具调用上限上调 + 调用过程可视化 + 调用日志

| 项 | 内容 |
| --- | --- |
| 上限 | 调用 6→10 次、轮数 6→12 轮；系统提示词中的「累计不超过 10 次」与常量同步修改（不同步会误导模型） |
| 持久化 | qa 检索诊断由 `queries` 字符串列表改为 `steps` 结构化列表 `[{query, count, auto?, error?}]`（query 截断 60 字）；自动补检与被拒调用也入列；`searches` = steps 数量（因此自动检索现在也计数） |
| SSE | 每次 `search_book` 调用产生一帧 `status(stage=search, reset=true)`，附带结构化 `search` 字段与统一文案「检索/自动检索「query」· 命中 N 段 / 调用被拒绝」 |
| UI | 等待回答时显示实时编号轨迹（每次调用一行，被拒调用暖色）；回答与历史消息下方提供默认折叠的「模型自主检索 N 次（含 M 次被拒绝的调用）」轨迹，不限于开发者模式 |
| 日志 | 每次调用写一条 `agent_search` 应用日志（被拒调用 level=warning）；前端日志面板显示为「工具检索」 |
| 验证 | 部署 `414bc1d3-0ce5-42bb-a047-9b7894ff5d14`；线上冒烟 3 次检索 / 13 段证据 / 12 个 C 标签，steps 持久化与日志行数一致；浏览器实测实时轨迹与折叠轨迹渲染正常 |

### 测试套件既有破损修复（与 agentic 无关）

修复三处早已存在、随套件规模暴露的问题：DOCX 无样式时写出空 `word/styles.xml` 导致解析错误（改为仅在有样式时写该成员）；DOCX 标题期望值未跟上 CJK 空格压缩行为；`test_reader` 全局替换 `threading.Thread` 导致播种锁测试从未真正跑过真线程（模块顶部捕获真实类）。当前套件 85 个用例全部通过。

## 2026-09-18

### 原文阅读模式与私人批注

| 项 | 内容 |
| --- | --- |
| 后端 | 新增 [study/reader.py](../study/reader.py)：由章节拼接规范全文（SHA-256 为 version），按约 2400 码点、空行边界切阅读块；浏览器偏移一律 UTF-16；引用 anchor 按 ordinal + section + page + 文本全等映射，失配返回 409；快照缓存 3 本书 / 64 MiB，解析前后复核源文件未中途变更 |
| 端点 | `GET /api/books/{id}/reader`（start/count、anchor、at、version 定位）与批注 CRUD（私有、每书每人 500 条、quote 全等校验、版本失配 409、PATCH 仅允许改笔记与颜色） |
| 前端 | 证据面板整体改为原文阅读（`web/reader.js`）：目录跳转、无限前后文加载与滚动锚定、选文高亮三色 + 笔记、重叠批注归入抽屉、引用定位蓝色底纹；旧证据面板的分块翻页与语义高亮前端代码删除（对应后端端点仍保留） |
| 边界 | 全文阅读与批注全程不调用 LLM 与 embedding；批注按账户隔离，删书级联删除 |
| 验证 | 线上冒烟（reader 200、批注增改删全通过）+ 索引轮询复核 + 浏览器移动端视觉检查；`tests/test_reader.py` 24 个用例 |
