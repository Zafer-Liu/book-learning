# 教材导入指南

[文档首页](README.md) · [项目架构](ARCHITECTURE.md) · [配置参考](CONFIGURATION.md)

把一本书放进「书内」只需要一份**UTF-8 编码的 Markdown / TXT / DOCX**。本文说明各格式的准备方式、章节识别规则与常见问题。

## 一、格式选择

| 你的原稿 | 建议路径 |
| --- | --- |
| 纯文本电子书（txt / md） | 直接上传,确认编码为 UTF-8 |
| Word 文档（docx） | 直接上传,系统自动抽取文字并识别标题 |
| 扫描版 PDF / 图片 | 先 OCR 转成 Markdown,再上传 |
| EPUB / MOBI | 用转换工具先转成 txt / md(如 Calibre),再上传 |

限制:单文件 ≤ 20 MB / 400 万字符;每账户默认 20 本、50 MB 原文件。

## 二、章节识别规则

索引与「检索章节」下拉都依赖标题结构:

- **Markdown**:识别 `#` / `##` / `###` 标题行(Atx 风格)。建议每章用 `# 章名`,节用 `## 节名`。
- **TXT**:识别独立成行的「第 X 章 / 第 X 节 / 一、二、三」等中文序号标题行。
- **DOCX**:识别 Word 内置的标题样式(标题 1/2/3);正文样式照常提取。

没有可识别标题时全文仍可检索,但章节导航与按章提问会退化为「全文一段」。

## 三、扫描版:OCR 到 Markdown

1. 用 OCR 工具把 PDF 逐页转文字。常用选择:
   - 本地批量:`PaddleOCR`、`pix2text`(中文效果好,命令行可批量);
   - 桌面软件:ABBYY FineReader、Adobe Acrobat 的「导出为文本」、WPS PDF 转文字。
2. OCR 输出通常是一页一段的散乱文本,上传前建议做三件事:
   - **合并章节**:把同一章的页段拼到一个 `# 章标题` 之下;
   - **删页眉页脚**:页码、书名重复行会污染检索;
   - **修明显错字**:OCR 错误会原样进入索引,检索与引用都受影响。
3. 公式、图表、脚注图片不会被识别;教材中重要的图表请在笔记中自行补充说明。

## 四、上传与验收

1. 登录后在书架点「＋」上传,选择分类(教材 / 文献)。
2. 等待状态变为「可以学习」;大部头首次索引需要一些时间。
3. 验收建议:
   - 打开「阅读全文」,确认目录层级和正文顺序正确;
   - 问一个书中明确写过的概念,确认引用能展开对应原文;
   - 若章节列表为空或乱序,检查标题行格式后「重新索引」(注意:重新索引会清除本书对话)。

## 五、常见问题

- **上传报「编码不受支持」**:文件不是 UTF-8。用编辑器(如 VS Code 右下角状态栏)转为 UTF-8 保存。
- **引用里的「页码」与纸质书不同**:Markdown 没有可靠页码,系统只标注真实的章节与正文位置。
- **一本书太大**:按卷/部拆分为多个文件分别上传,分卷提问。
- **想要更正内容**:修正源文件后重新上传或替换,重索引会使旧引用失效(旧对话会被清除,防止引用指向错误新分块)。
