## 当前实现范围

| 领域 | 已实现 | 需要注意 |
| --- | --- | --- |
| 账户 | 自选用户名与密码、会话认证、CSRF、测试码或个人 API Key 注册 | 无测试码注册必须自带 API Key；测试码注册与 BYO 注册受 `STUDY_REGISTRATION_OPEN` 总开关控制 |
| 教材 | 私有 Markdown/TXT/DOCX 上传（DOCX 自动提取文字与章节标题）、共享内置教材、后台分块索引 | 不解析 PDF，不提供 OCR；DOCX 标题识别是启发式，图片不转录 |
| 学习 | 问答、章节讲解、要点梳理、自测，按书保存与删除对话 | 问答模式由模型自主多轮检索；其余模式固定检索。一次只检索当前书，可进一步限定章节；不是跨书知识库 |
| RAG | 词法、SQLite FTS5、可选语义向量、RRF 融合；qa 模式检索本身是模型可调用的工具 | 向量不可用时降级；引用编号合法不保证结论正确 |
| 生成 | 结构化回答、正文流式、主备模型 | 首个可见增量之后不切换备用；自测生成仍是一次性 |
| 原文阅读 | 引用定位到阅读器正文、目录跳转、滚动连续浏览全文、三色高亮与笔记批注 | 阅读与批注不调用模型；批注按账户隔离且随书版本校验 |
| 反馈 | 满意/不满意、可选原因、事件归档、三日汇总 | 按事件计数，不是去重满意率；没有自动训练或调参 |
| 运维 | 健康检查、应用日志、单实例 Docker/Railway 部署 | 需要外部挂载持久卷；没有分布式队列或管理员面板 |

当前 `builtin_books/` 中有《行政诉讼法》《刑事诉讼法通义》《民法 第八版 魏振瀛》《利维坦》《宪法学》五本教材。《民法》由五份 DOCX 按 1–910 页文件顺序合并，保留七编、四十八章和 240 个节标题；转换保留可提取文本及分节页脚中的脚注（25 条页脚均已按分节锚点接续或补入），不包含图片转录，原 OCR 错误仍可能存在。《宪法学》由三本宪法教材按 第二版→讲义→新时代 顺序合并为单本（各保留自己的 h1）。部署后需确认新书索引 ready 才能使用。

## 文档边界

本文档根据当前工作区源码编写，不将历史部署记录视作当前线上验证；按日期的上线与验证记录统一放在[进展记录](PROGRESS.md)，不写入专题文档正文。

根目录的 README 是项目主文档(中英双语)。当前课程助手以本目录的分专题说明为入口,具体行为最终以源码为准。

文档不保存 API 密钥、会话密钥、密码、可用测试码、用户活动清单或私人机器路径。生产配置以部署平台 Variables 为准，不能用 `.env.example` 推断线上配置。

保持 UTF-8、LF 换行；链接优先使用仓库内相对路径。更新时区分“源码支持”“部署配置”“实际验证结果”，不要把一次人工验证写成永久保证。
